# HydraCor — ToDo

HydraCor is a focused, lightweight ToDo app built with Vue 3 and Tailwind. This branch contains a UI polish to make the app feel more like a polished product (blue & white theme).

Features

- Add, edit, and delete tasks
- Local persistence (browser storage)
- Responsive layout with app-like header and sidebar
- Modal edit panel and task cards

Run locally

1. npm install
2. npm run dev
3. Open http://localhost:5173

Preview branch
This UI polish was applied on branch `feature/ui-blue`.

Notes

- This change focuses on frontend styling and layout only — no backend or auth was added.
- If you want authentication, persistence across devices, or a live deployment, I can add Supabase/Firebase integration and deploy to Vercel/Netlify.
